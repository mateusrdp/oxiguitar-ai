# Requirements and assumptions

## Requirements

- OxiGuitar 0.23.0 or later (plugin interface 1.16). See [the OxiGuitar manual](https://mateusrdp.github.io/oxiguitar/).
- A language model server, on your computer or hosted.
- Windows, macOS or Linux.

## Assumptions

- You supply the server, the model and any key.
- A model that supports tool calling is needed for anything beyond a plain conversation.
- The model's output is a suggestion. You can undo it and you should listen to it.
